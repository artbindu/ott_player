# [OTT Media Player](https://artbindu.github.io/ott_player/)

A lightweight OTT-style media player built with HTML, CSS, and JavaScript. It supports local files, folders, playlists, and URL playback, with advanced controls including playback speed, fullscreen, Picture-in-Picture, theater mode, video effects, rotation, trim & loop, FFmpeg script generation, keyboard shortcuts, and a responsive UI.

## OTT Sample Players

Explore the player integrations in the [OTT Sample Player](https://artbindu.github.io/ott_player/samplePlayer/) gallery:

- [DASH.js](https://artbindu.github.io/ott_player/samplePlayer/dashjs/)
- [Bitmovin](https://artbindu.github.io/ott_player/samplePlayer/bitmovin/)
- [RxPlayer](https://artbindu.github.io/ott_player/samplePlayer/rxplayer/)
- [Native HLS](https://artbindu.github.io/ott_player/samplePlayer/hls/) (requires browser-native HLS support)

- 🔄 Rotation
- ✂️ Trim & Loop

## Getting Started

```bash
git clone <repository-url>
cd ott_player
npm install
npm start
```

Open: `http://localhost:54321`

## Build

```bash
npm run build
```
